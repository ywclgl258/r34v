# R34V 界面规范

目标是让用户从完整封面迅速进入观看，并容易回到上次进度。参考 Netflix Android 的内容层级、轮播与纵向浏览，沿用 R34V 数据与原生播放行为。

## 视觉

| 用途 | 规范 |
| --- | --- |
| 画布 / 表面 | #000000 / #141414、#1F1F1F |
| 主要文字 / 次要文字 | #FFFFFF / #B3B3B3、#A6A6A6 |
| 品牌、进度、开关 | Netflix 红 #E50914 |
| 小号强调文字 / 控件描边 | #FF6670 / #747474 |
| 加载场景 | 暖黑 #0C0A09 / 珊瑚红 #E4695D |
| 主播放 / 次操作 | 白底黑字 / 深灰实底白字 |
| 标题 / 分组 / 正文 / 元信息 | 精选24sp、详情22sp / 18–20sp / 14–16sp / 12sp |
| 内容边距 / 间距 | 16–20dp / 6、8、12、16、24dp |
| 封面 / 控件圆角 | 3dp / 6dp；筛选为24dp圆角 |
| 点击区域 | 至少48dp，底部导航至少64dp；封面更多按钮视觉32dp、触控48dp |

黑底固定，不使用宣传截图外侧红色渐变。完整16:9封面承担视觉主体，首页轮播使用全宽内容行，标题与播放动作紧随其后；不使用伪竖版海报或自动视频预览。保持图片原有数据来源。播放、收藏、下载使用同一套矢量图标，不混用字符图标。

## 页面与状态

- 首页：顶部轮播展示热门、高分两个排行的视频，保留下排行标签、播放与收藏。下方直接是最新视频纵向瀑布流，不再显示继续观看、榜单入口或横向片架；手机双列、平板三列，接近末尾时分页加载。
- 导航：首页/发现/搜索/片库固定。选中项使用灰底图标容器、加粗文字和原生选中语义，不只依赖颜色。顶栏站点名称单行省略，旁边保留下拉箭头，给下载和设置保留固定48dp空间；二级列表延续所属导航状态。
- 发现：热门榜突出，最新/高分/为你推荐为轻量入口，分类、角色作品和作者索引集中排列。
- 搜索：视频/标签/作者范围可见，显示当前搜索站点；键盘搜索与搜索图标直接提交，空提交显示“请输入关键词”。输入框尾部支持一键清除且不改变搜索范围；返回结果前的范围和关键词保留，最近搜索可清空。
- 片库：观看/收藏/下载三类任务；收藏下保留视频/角色/作者/标签。空态明确区分记录、收藏与下载，并提供“去发现”。现有历史、收藏与下载存储格式不变；视频收藏可通过更多菜单取消。
- 播放：画面优先，完整标题、参数、收藏下载依次分层。清晰度与倍速使用紧凑描边控件并保留48dp触控区域，更多使用图标；收藏与下载使用轻量文字图标按钮。首缓冲目标为8秒，起播与再缓冲阈值保持400ms/800ms。简介、标签与评论可展开；相关视频为双列16:9。“重新播放”在更多菜单，错误时显示重试。状态文案同步播放/暂停。
- 设置：连续的灰黑分组，触控行随文字高度扩展。空态说明下一步，网络/解析失败保留重试入口，离线列表明确标记缓存。
- 漫画：首页、搜索与画廊片库使用原生瀑布流，完整封面按自身比例显示，未知尺寸先占位再按实际图像修正；手机双列、宽屏增加列数。标题、提示和分页入口跨列，不把漫画封面裁成视频横幅。
- 漫画语言：浏览页面顶栏下使用48dp高的单排“全部 / 中文 / 日文 / 中＋日”，标签底形更薄，保留48dp触控区；窄屏及大字体可横滑，不折行。下滑18dp后收起，上滑或回到顶部时显示。按站点保存选择；切换保留当前搜索或分类，重置分页。片库保留用户主动保存的全部记录。
- 漫画阅读：宽度适配屏幕、按原比例上下连续排列，滑动跨页并更新进度；单击画面隐藏/显示顶栏和底栏，顶栏另有全屏入口。隐藏菜单时同时隐藏系统状态栏/导航栏；返回键先恢复菜单，重建时保留全屏状态。双指/双击缩放与上下滚动互不触发菜单切换。预读后续三页，屏外解码缓存不超过24MiB；失败页原位重试，恢复阅读时还原页内位置。
- 视频播放选择器：清晰度和倍速沿用统一的48dp按钮，文字、16dp箭头和内边距分别占位；背景设置完成后再设置相对内边距，避免文字贴边。大字体仍保持值与箭头单行，必要时在控件之间换行。
- 切站：顶栏使用14sp站名与小箭头，首页只出现一次站名；抽屉行只保留站名、当前状态和必要的权限提示，移除重复域名，触控区至少48dp。
- 首次切站教程：仅全新安装首次进入首页时，在真实切站入口下显示带指向箭头的深色提示卡，并描边高亮入口。“打开站点列表”直接展开原有抽屉，“知道了”、返回或点击卡片外可关闭；首次显示即持久记录，后续切站、重建或重启不重复，升级及旧数据迁移用户不弹出。提示不等待联网结果；大字体下卡片随文字增长，空间不足时可滚动。
- ExHentai：抽屉标注账号权限要求；无会话时显示登录门禁及白屏原因，主操作打开官方论坛认证，保留站点设置中的 Cookie 导入入口。权限验证失败的解释持续保留，不能被延迟到达的论坛页面完成回调改写为初始提示。授权验证成功后返回原生浏览。

文字服从系统字体大小；标题与操作不依赖固定高度，大字体参数与筛选可换行，标签测量宽度不得超过扣除左右内边距后的空间。轮播标题最多两行并保留稳定高度，瀑布流浏览卡标题最多两行；详情标题完整换行。600dp及以上宽屏将首页精选的完整16:9封面与信息并排显示，旋转时保留当前轮播页。设置值限制最大宽度，为项目名称保留空间。

共享控件使用原生 Ripple、独立键盘焦点描边和禁用状态；顶栏站点入口、底部导航与轮播页码补充按钮语义。正文灰色在 #141414 上对比度约7.57:1，小号红色文字在黑底上约7.39:1，描边在 #141414 上约3.94:1。进度条、开关仍使用品牌红；不以深红色承担小号正文。

轮播提供暂停/继续按钮；手动翻页不撤销用户暂停。48dp指示器在窄屏上可横向滚动。窗口失去焦点、触摸探索开启、页面不可见或系统关闭动画时不自动翻页。

本轮采用 `ui-ux-pro-max` 中已核对的 Dark Mode (OLED)、电影内容优先方向与 Android 触控建议，字体继续使用系统 sans。触控和语义参照 [Android 原生无障碍规范](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)。

## 动效与范围

原生 Ripple 反馈按压，页面首次进入160ms淡入，信息展开箭头180ms反馈；遵守系统动画开关。首页轮播每6.5秒切换，支持封面左右滑动和指示器直接切换；页面不可见、触摸滑动或系统关闭动画时停止自动轮播。加载使用细环、播放三角与低亮度光晕，旋转周期2.8秒、呼吸周期3.6秒，仅在可见且系统允许动画时运行。首次打开显示完整加载场景，播放中缓冲只覆盖画面；阶段由真实连接、准备、缓冲与就绪状态驱动，不显示模拟百分比，就绪后220ms淡出，失败立即退出。除此之外不引入循环吸引注意的动效。网络设置统一说明系统代理/直连策略，不再提供 Host/IP 或应用内代理开关；签名、播放引擎、下载服务和数据迁移规则不变。
