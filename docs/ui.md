# R34V 界面规范

目标是让用户从完整封面迅速进入观看，并容易回到上次进度。参考 Netflix Android 的内容层级、轮播与纵向浏览，沿用 R34V 数据与原生播放行为。

2.2.0起全部应用界面使用Jetpack Compose + Material 3。2.2.1 首页使用 LazyColumn + LazyRow 片架与 HorizontalPager Hero，站内查询和漫画保留 LazyVerticalStaggeredGrid。主导航/切站使用 Scaffold 与 ModalNavigationDrawer；封面统一使用 Coil AsyncImage。仅 Media3 画面及官方认证 WebView 使用 AndroidView。详细迁移与验证见 [Compose说明](dev/compose-migration.md)。

## 视觉

| 用途 | 规范 |
| --- | --- |
| 画布 / 表面 | #000000 / #14171B、#1C2025 |
| 主要文字 / 次要文字 | #FFFFFF / #B4BAC3 |
| 品牌、进度、开关 | Netflix 红 #E50914 |
| 评分 / 预览匹配度 | #46D369；生产界面只显示站点真实评分，不生成匹配百分比 |
| 玻璃叠层 / 控件描边 | 中性黑灰渐变 #D117191D→#EB0C0E11 / 白色22%→3.5%高光细边 |
| 加载场景 | 暖黑 #0C0A09 / 珊瑚红 #E4695D |
| 主播放 / 次操作 | 白底黑字 / 深灰磨砂底白字；共享主操作保持红底白字 |
| 标题 / 分组 / 正文 / 元信息 | Hero 26sp、页面18sp / 15sp / 12–13sp / 10–11sp |
| 内容边距 / 间距 | 16–18dp / 2、3、6、8、10、12、14、16、24dp |
| 封面 / 控件圆角 | 封面14dp / 按钮14dp、按下11dp、搜索16dp、玻璃面板16–28dp、筛选17dp、Dock 23dp |
| 点击区域 | 至少48dp；悬浮 Dock 横屏56dp、其余66dp；小视觉图标仍保留48dp命中区 |

黑底固定。Hero 约为屏高59%，封面延伸到透明顶栏下方，上方暗化、底部 Transparent→Black 渐变无缝融入画布。视频海报片架统一110×165dp、间距12dp、水平边距18dp，使用 ContentScale.Crop；漫画封面仍按实际比例完整显示。材质分为银幕、烟熏玻璃和磨砂实体三层，玻璃主要用于悬浮导航、顶栏、播放控制、主按钮组和弹层，普通内容卡保持磨砂实底。`GlassSurface` 在 Android 12+ 对少量封面背景使用28dp原生模糊，Android 7–11 使用中性渐变与高光细边降级，不依赖新增模糊库。保持图片原有数据来源，不自动播放预览。播放、收藏、下载使用矢量图标。

## 页面与状态

- 首页：全幅 Hero 提供白底播放与玻璃片单按钮，收藏状态即时更新；下方为真实可续播记录、人气榜 Top 10、高分与最新更新横向片架。首页列表为悬浮 Dock 预留72dp避让，续播标题和进度不被遮挡。无可续播记录时不显示空片架，可选榜单超时不阻塞最新内容。最新更新分组追加并自动分页；“查看全部”进入原有完整查询列表。宽横屏压缩 Hero 并隐藏顶栏筛选，200% 字体增加 Hero 高度，允许页面滚动。
- 导航：首页/发现/搜索/片库固定为悬浮玻璃 Dock，横屏56dp、其余66dp，最大宽度620dp。选中项使用滑动磨砂底、加粗白字和原生选中语义。首页顶部为 R34V 标识、站点下拉、搜索与头像设置；片库保留订阅和设置入口，下载进入片库任务标签。站名单行省略，所有操作保留48dp触控区；二级列表延续所属导航状态。收藏、切站和订阅等结果使用位于 Dock 上方的 Snackbar，不再用系统 Toast 遮挡操作。
- 发现：热门榜作为第一视觉锚点，最新/高分/为你推荐为轻量入口，分类、角色作品和作者索引集中排列。
- 搜索：不再重复宣传式大标题，当前站点说明、输入框、视频/标签/作者范围和最近搜索连续排列。键盘搜索与搜索图标直接提交，空提交显示“请输入关键词”。输入框尾部支持一键清除且不改变搜索范围；返回结果前的范围和关键词保留，最近搜索可清空。
- 片库：视频站为观看/收藏/下载，漫画站为阅读/收藏/下载；页头压缩为单行信息，收藏类别继续按站点提供。两种媒体共用下载中心，默认汇总全部站点，提供全部内容/视频/漫画和来源站点筛选，卡片显示源站、清晰度或页数、进度、大小和可操作状态。视频可离线播放，漫画可整本离线阅读；暂停、继续/重试和删除入口统一。旧版视频缓存直接作为已下载内容显示，无需重新下载。
- 播放：画面优先，顶部与底部控制带使用少量玻璃层，进度条只有单个播放位置标记。清晰度与倍速使用紧凑描边控件并保留48dp触控区域，更多使用图标；收藏与下载使用轻量文字图标按钮。首缓冲目标为8秒，起播与再缓冲阈值保持400ms/800ms。简介、标签与评论可展开；相关视频为双列16:9。“重新播放”在更多菜单，错误时显示重试。状态文案同步播放/暂停。
- 设置：连续的灰黑分组，触控行随文字高度扩展。空态说明下一步，网络/解析失败保留重试入口，离线列表明确标记缓存。
- 漫画：首页、搜索与画廊片库使用原生瀑布流，完整封面按自身比例显示，未知尺寸先占位再按实际图像修正；手机双列、宽屏增加列数。标题、提示和分页入口跨列，不把漫画封面裁成视频横幅。
- 漫画语言：浏览页面顶栏下使用48dp高的单排“全部 / 中文 / 日文 / 中＋日”，标签底形更薄，保留48dp触控区；窄屏及大字体可横滑，不折行。下滑18dp后收起，上滑或回到顶部时显示。按站点保存选择；切换保留当前搜索或分类，重置分页。片库保留用户主动保存的全部记录。
- 漫画阅读：宽度适配屏幕、按原比例上下连续排列，滑动跨页并更新进度；单击画面隐藏/显示顶栏和底栏，顶栏另有全屏入口。隐藏菜单时同时隐藏系统状态栏/导航栏；返回键先恢复菜单，重建时保留全屏状态。双指/双击缩放与上下滚动互不触发菜单切换。预读后续三页，屏外解码缓存不超过24MiB；失败页原位重试，恢复阅读时还原页内位置。
- 漫画下载：详情提供下载整本、暂停/继续/重试、离线阅读和管理下载；下载中心与视频共用。临时阅读图页不自动冒充整本下载，已读文件会在主动下载时复用。清理临时数据保留整本下载、收藏和阅读记录。通知点击进入统一下载中心；系统后台时限到达时保留已下载页并暂停，用户可继续。
- 视频播放选择器：清晰度和倍速沿用统一的48dp按钮，文字、16dp箭头和内边距分别占位；背景设置完成后再设置相对内边距，避免文字贴边。大字体仍保持值与箭头单行，必要时在控件之间换行。
- 切站：顶栏使用11sp站名与小箭头，首页只出现一次站名；抽屉行只保留站名、当前状态和必要的权限提示，移除重复域名，触控区至少48dp。
- 首次切站教程：仅全新安装首次进入首页时，在真实切站入口下显示带指向箭头的深色提示卡，并描边高亮入口。“打开站点列表”直接展开原有抽屉，“知道了”、返回或点击卡片外可关闭；首次显示即持久记录，后续切站、重建或重启不重复，升级及旧数据迁移用户不弹出。提示不等待联网结果；大字体下卡片随文字增长，空间不足时可滚动。
- ExHentai：抽屉标注账号权限要求；无会话时显示登录门禁及白屏原因，主操作打开官方论坛认证，保留站点设置中的 Cookie 导入入口。权限验证失败的解释持续保留，不能被延迟到达的论坛页面完成回调改写为初始提示。授权验证成功后返回原生浏览。

文字服从系统字体大小；标题与操作不依赖固定高度，大字体参数与筛选可换行，标签测量宽度不得超过扣除左右内边距后的空间。Hero 标题最多两行，瀑布流浏览卡标题最多两行；详情标题完整换行。宽横屏采用较矮全幅 Hero，保留播放与片单空间；旋转时保留当前轮播页。设置值限制最大宽度，为项目名称保留空间。

共享控件使用 Compose Material 3 的 Ripple、键盘焦点反馈、禁用状态和交互语义；顶栏站点入口、底部导航与轮播页码提供明确语义。按钮按下缩至0.97、圆角14→11dp并减弱阴影，松开短促回弹；选中筛选使用白底黑字，Dock 使用滑动磨砂底。清晰度、倍速和其他单选操作使用接近不透明的玻璃底部面板，避免底层文字透入并显示当前选中项；搜索提交使用独立箭头图标，危险确认与输入继续使用圆角对话框。进度条、开关和品牌标识使用 Netflix 红；Hero 播放使用白底黑字，共享主按钮使用红底白字，文本操作统一白色。

轮播提供暂停/继续按钮；点击页码指示器后暂停自动切换。48dp指示器在窄屏上可横向滚动。页面不可见、触摸探索开启或系统关闭动画时不自动翻页。

封面由 Coil AsyncImage 按布局约束解码，共享24MiB内存与64MiB磁盘缓存；缓存键包含站点，网络请求显式携带所属站点并动态取得现有 Network.client，保留 User-Agent、Referer、Cookie 隔离和系统代理更新。漫画图页的独立预读/缩放缓存不变。流媒体影片名、演示匹配度和参考海报只进入 Debug 玻璃预览与 AndroidTest APK，用于可复现原生截图，不进入 Release APK。Debug 预览用于预先验证视觉，生产页面已复用同一设计方向，两者入口与组件保持独立。

本轮采用“暗室玻璃影院”方向：银幕、烟熏玻璃与磨砂实体三层材质，字体继续使用系统 sans。触控和语义参照 [Android 原生无障碍规范](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)。

## 动效与范围

原生 Ripple 反馈按压，按钮约80ms压下、160ms释放，筛选和 Dock 状态约200ms过渡，页面首次进入160ms淡入，信息展开箭头180ms反馈；遵守系统动画开关。首页轮播每6.5秒切换，支持封面左右滑动和指示器直接切换；页面不可见、触摸滑动或系统关闭动画时停止自动轮播。加载使用细环、播放三角与低亮度光晕，旋转周期2.8秒、呼吸周期3.6秒，仅在可见且系统允许动画时运行。首次打开显示完整加载场景，播放中缓冲只覆盖画面；阶段由真实连接、准备、缓冲与就绪状态驱动，不显示模拟百分比，就绪后220ms淡出，失败立即退出。悬浮感来自材质、按压和滚动，不使用永久循环漂浮。网络设置统一说明系统代理/直连策略，不再提供 Host/IP 或应用内代理开关；签名、播放引擎、下载服务和数据迁移规则不变。
