# R34V 界面规范

目标是让用户从完整封面迅速进入观看，并容易回到上次进度。参考 Netflix Android 的内容层级、轮播与纵向浏览，沿用 R34V 数据与原生播放行为。

## 视觉

| 用途 | 规范 |
| --- | --- |
| 画布 / 表面 | #000000 / #141414、#1F1F1F |
| 主要文字 / 次要文字 | #FFFFFF / #B3B3B3、#8C8C8C |
| 品牌、进度、开关 | Netflix 红 #E50914 |
| 加载场景 | 暖黑 #0C0A09 / 珊瑚红 #E4695D |
| 主播放 / 次操作 | 白底黑字 / 深灰实底白字 |
| 标题 / 分组 / 正文 / 元信息 | 精选28sp、详情22sp / 17–18sp / 14–16sp / 12sp |
| 内容边距 / 间距 | 16–20dp / 6、8、12、16、24dp |
| 封面 / 控件圆角 | 3dp / 4dp；筛选为3dp低圆角 |
| 点击区域 | 至少44dp，底部导航至少64dp |

黑底固定，不使用宣传截图外侧红色渐变。完整16:9封面承担视觉主体，首页轮播使用全宽内容行，标题与播放动作紧随其后；不使用伪竖版海报或自动视频预览。保持图片原有数据来源。播放、收藏、下载使用同一套矢量图标，不混用字符图标。

## 页面与状态

- 首页：顶部轮播展示热门、高分两个排行的视频，保留下排行标签、播放与收藏。下方直接是最新视频纵向瀑布流，不再显示继续观看、榜单入口或横向片架；手机双列、平板三列，接近末尾时分页加载。
- 导航：首页/发现/搜索/片库固定。下载和设置位于稳定的顶部入口；二级列表延续所属导航状态。
- 发现：热门榜突出，最新/高分/为你推荐为轻量入口，分类、角色作品和作者索引集中排列。
- 搜索：视频/标签/作者范围可见；键盘搜索与搜索图标直接提交；返回结果前的范围和关键词保留，最近搜索可清空。
- 片库：观看/收藏/下载三类任务；收藏下保留视频/角色/作者/标签。现有历史、收藏与下载存储格式不变；视频收藏可通过更多菜单取消。
- 播放：画面优先，完整标题、参数、收藏下载依次分层。清晰度与倍速使用36dp视觉高度的紧凑描边控件并保留44dp触控区域，更多使用图标；收藏与下载使用轻量文字图标按钮。首缓冲目标为8秒，起播与再缓冲阈值保持400ms/800ms。简介、标签与评论可展开；相关视频为双列16:9。“重新播放”在更多菜单，错误时显示重试。状态文案同步播放/暂停。
- 设置：连续的灰黑分组，触控行随文字高度扩展。空态说明下一步，网络/解析失败保留重试入口，离线列表明确标记缓存。

文字服从系统字体大小；标题与操作不依赖固定高度，大字体参数与筛选可换行。轮播标题最多两行并保留稳定高度，瀑布流浏览卡标题最多两行；详情标题完整换行。

## 动效与范围

原生 Ripple 反馈按压，页面首次进入160ms淡入，信息展开箭头180ms反馈；遵守系统动画开关。首页轮播每6.5秒切换，支持封面左右滑动和指示器直接切换；页面不可见、触摸滑动或系统关闭动画时停止自动轮播。加载使用细环、播放三角与低亮度光晕，旋转周期2.8秒、呼吸周期3.6秒，仅在可见且系统允许动画时运行。首次打开显示完整加载场景，播放中缓冲只覆盖画面；阶段由真实连接、准备、缓冲与就绪状态驱动，不显示模拟百分比，就绪后220ms淡出，失败立即退出。除此之外不引入循环吸引注意的动效。签名、直连、代理、播放引擎、下载服务和数据迁移沿用已验证路径。
