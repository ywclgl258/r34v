# R34V 界面规范

## 当前导航：2.7.1（2026-11-09）

默认启动页和底部“首页”展示当前站点的精选、榜单及最新内容，观看历史不替换站点首屏。底栏为“首页 / 发现 / 搜索 / 片库 / 我的”，等宽五项，保留黑底和选中语义。切站仍进入首页；从一级页面返回回到首页，首页再返回退出。

“我的”承接原个人首页的跨站续看、稍后看、订阅更新、常用搜索及个人频道。数据格式、现有记录和片库入口不变。下方各版本记录保留历史背景，导航定义以本节为准。

## 2.7.0 开发记录：结构重构（2026-11-08）

在 2.6.0 的纯黑、白色主操作和红色强调色基础上，个人首页改为融入画布的全幅封面、紧贴作品的进度与继续操作，下接真实内容片架。顶部“全部 / 视频 / 漫画 / 写真”只筛选个人内容，保留选择以支持 Activity 重建。漫画完整显示书封；200% 字体时图片与标题分开，大屏则左右排布。工具入口放在片架之后，完成作品仍不充当续播主角。

片库顶栏统一显示“我的片库”，记录、收藏、下载、更新为轻量快捷入口；“我的片单 / 智能片单 / 本地内容”一次展示一个分区。分区选择可恢复，单图收藏、标签订阅、文件导入和链接打开仍可滚动到达。大字体工具改为两列图文行，手机片单占满可用宽度。

搜索保留输入、当前／多个站点、高级筛选及保存方案的能力，移除重复来源说明和没有切换意义的单个“关键词”选项。只有存在可保存条件时出现保存按钮；常用搜索同时显示名称与查询，更新未读入口保持可见。

从首页打开片单直接进入整理页，省去重复导航层。上移／下移后将刚移动的作品滚到可见位置，便于立即确认结果。新增类型标签保留 Tab 选中语义与至少 48dp 触控区；固定底栏四个入口及现有播放、阅读、下载和导入行为沿用。

本节描述本地开发版本，正式版本仍为 2.6.0 / 46。实现与验证见 [结构重构记录](dev/ui-restructure-2026-11-08.md)。

同日片库增强：片单标题旁的搜索按钮展开标题／来源检索；输入时收起次要管理操作，键盘“搜索”收起输入以便查看结果。筛选面板增加加入时间和显示顺序；显示排序不修改手动顺序，顺序播放与离线准备使用当前结果。合集设置集中名称、备注、置顶与作品封面选择，点击保存后统一提交；置顶合集优先展示，备注最多显示两行。旧合集默认不置顶、无备注、自动封面。见 [功能验收](dev/shelf-features-2026-11-08.md)。

## 2.6.0 约定

保留纯黑画布、白色主操作和红色强调色 `#FF3547`，共享控件底色为 `#272727`。主按钮／封面使用 8dp 圆角，选择器 10dp、主封面块 12dp、阅读工具条 14dp。固定黑色底栏四项保持可见，手机 64dp、宽屏或横屏 52dp，并随字体增高；选中位置用红色短线和白色图文表示。页面按 Scaffold 的实际底栏安全区布局，不再覆盖导航。设置图标为齿轮。

个人首页按真实状态显示继续观看／阅读／浏览，已完成作品不再回落到继续主卡；稍后看片单直接标为“我的稍后看”。片库手机单列使用完整可用宽度，大字体快捷入口重排为两列、片单计数按短语换行；单图收藏同样修复错误补空列。搜索框置顶，作用范围说明保留在高级筛选与结果中。

主页不再录制玻璃导航背景。媒体控制层保留 18dp 模糊与旧系统／减少透明效果时的实色降级，移除装饰描边、阴影和边缘折射；触控范围仍至少 48dp。原生 Ripple、导航约 220ms 过渡、可暂停轮播沿用原有交互。实现与实测边界见 [改版记录](dev/modern-ui-2026-11-08.md)。下方为历次设计背景；与本节冲突的旧 Dock、材质和色值描述以本节为准。

## 历史设计背景

2.4.0 功能入口：首页为跨来源个人首页；发现页可进入当前来源的原有精选、榜单与分类。片库首页用封面组织固定合集和智能片单，并直达记录、收藏、下载与全局更新。合集筛选集中到面板，顺序观看／阅读需主动启动，下一项必须确认；小屏上下浏览，大屏列表与选中详情并列，短横屏时操作区可随内容滚动。

搜索页可保存和管理搜索方案；跨站结果按来源分组并独立翻页／重试，保存条件包含来源、类型与漫画语言。浏览器分享文本链接在识别和打开前确认；片库提供粘贴入口。离线准备区分已离线、已排队、未下载，未知大小保持未知。阅读工具提供页面缩略图总览、书签、模式与全屏入口；片库可用系统文件／目录选择器导入本地漫画，导入复制到应用内，保留原始文件。

2.3.0 已有的页码书签与阅读模式、防误触、定时暂停、画中画、下载网络条件、批量管理和加密备份继续保留。黑底固定，主动作统一白底黑字，珊瑚红用于品牌和进度，触控区域至少 48dp；勾选列表整行提供复选语义，长名称换行。

2.4.0 追加三类媒体全面改版：参考 AndroidLiquidGlass 与 apple-design-skill，将玻璃限制在导航和控制层，封面及正文使用稳定内容层。视频保留精选片架；漫画采用书封续读块；写真采用图集主图与逐图翻页。详情、搜索、片库、下载、设置和弹窗共享新字体、白色主动作与中性次操作。实现、版本降级和证据边界见 [三类媒体改版](dev/liquid-ui-2026-11-06.md)。

目标是让用户从完整封面迅速进入观看，并容易回到上次进度。参考 Netflix Android 的内容层级、轮播与纵向浏览，沿用 R34V 数据与原生播放行为。

2.2.0起全部应用界面使用Jetpack Compose + Material 3。2.2.1 首页使用 LazyColumn + LazyRow 片架与 HorizontalPager Hero，站内查询和漫画保留 LazyVerticalStaggeredGrid。主导航/切站使用 Scaffold 与 ModalNavigationDrawer；封面统一使用 Coil AsyncImage。仅 Media3 画面及官方认证 WebView 使用 AndroidView。详细迁移与验证见 [Compose说明](dev/compose-migration.md)。

黑底固定。视频来源无续播记录时，手机 Hero 约为屏高59%，宽屏紧凑密度下扣除156dp（至少280dp）；封面延伸到透明顶栏下方，上方暗化、底部 Transparent→Black 渐变无缝融入画布。视频海报片架在手机上为110×165dp、间距12dp、水平边距18dp；宽屏为96×144dp、间距10dp、边距16dp，使用 ContentScale.Crop；漫画封面仍按实际比例完整显示。2.2.6 起以内容和中性灰阶填充建立层级：按钮、卡片、设置行和浮层不使用装饰线框，浮层只保留轻渐变和克制阴影。Hero 与播放器详情的按钮直接排布，不再额外包裹一层玻璃框。`GlassSurface` 在 Android 12+ 对少量封面背景使用28dp原生模糊，Android 7–11 使用无描边中性实底或渐变降级，不依赖新增模糊库。保持图片原有数据来源，不自动播放预览。播放、收藏、下载使用矢量图标。

## 页面与状态

- 视频来源首页：有记录时优先显示单一续播对象，无记录时全幅 Hero 提供白底播放与深灰片单按钮，收藏状态即时更新；下方为真实可续播记录、人气榜 Top 10、高分与最新更新横向片架。首屏内容自然延伸至悬浮 Dock，不设置固定黑色留白；仅在列表末尾保留足够的滚动避让并随字体增高，确保最后的标题和进度可完整滚离 Dock。无可续播记录时不显示空片架，可选榜单超时不阻塞最新内容。最新更新分组追加并自动分页；“查看全部”进入原有完整查询列表。宽横屏压缩 Hero 并隐藏顶栏筛选，200% 字体增加 Hero 高度，允许页面滚动。
- 导航：首页/发现/搜索/片库固定为悬浮玻璃 Dock，内项宽屏48dp、其他横屏52dp、其余60dp；宽屏外边距8dp、其余10dp，随字体增高，最大宽度宽屏520dp、其余620dp。选中项使用滑动磨砂底、加粗白字和原生选中语义。首页顶部为 R34V 标识、站点下拉、搜索与头像设置；片库保留订阅和设置入口，下载进入片库任务标签。站名单行省略，所有操作保留48dp触控区；二级列表延续所属导航状态。收藏、切站和订阅等结果使用位于 Dock 上方的 Snackbar，不再用系统 Toast 遮挡操作。
- 发现：热门榜作为第一视觉锚点，最新/高分/为你推荐为轻量入口，分类、角色作品和作者索引集中排列。
- 搜索：不再重复宣传式大标题，当前站点说明、输入框、视频/标签/作者范围和最近搜索连续排列。键盘搜索与搜索图标直接提交，空提交显示“请输入关键词”。输入框尾部支持一键清除且不改变搜索范围；返回结果前的范围和关键词保留，最近搜索可清空。
- 片库：视频站为观看/收藏/下载，漫画站为阅读/收藏/下载；页头压缩为单行信息，收藏类别继续按站点提供。两种媒体共用下载中心，默认汇总全部站点，提供全部内容/视频/漫画和来源站点筛选，卡片显示源站、清晰度或页数、进度、大小和可操作状态。视频可离线播放，漫画可整本离线阅读；暂停、继续/重试和删除入口统一。旧版视频缓存直接作为已下载内容显示，无需重新下载。
- 播放：画面优先，顶部与底部控制带使用少量玻璃层，进度条只有单个播放位置标记。竖屏详情按“20sp标题与元信息、播放状态胶囊、清晰度/倍速、收藏/下载、内容卡片”组织；清晰度与倍速使用紧凑灰色填充控件并保留48dp触控区域，收藏使用填充选中态与“已收藏”文案，下载使用图标按钮。简介、标签与评论使用无描边展开卡，箭头随展开旋转；相关视频为双列16:9。首缓冲目标为8秒，起播与再缓冲阈值保持400ms/800ms。“重新播放”在更多菜单，错误时显示重试，状态文案同步播放/暂停。
- 设置：连续的灰黑分组，触控行随文字高度扩展。空态说明下一步，网络/解析失败保留重试入口，离线列表明确标记缓存。
- 漫画：首页、搜索与画廊片库使用原生瀑布流，完整封面按自身比例显示，未知尺寸先占位再按实际图像修正；手机双列、宽屏增加列数。标题、提示和分页入口跨列，不把漫画封面裁成视频横幅。
- 漫画语言：浏览页面顶栏下使用48dp高的单排“全部 / 中文 / 日文 / 中＋日”，标签底形更薄，保留48dp触控区；窄屏及大字体可横滑，不折行。下滑18dp后收起，上滑或回到顶部时显示。按站点保存选择；切换保留当前搜索或分类，重置分页。片库保留用户主动保存的全部记录。
- 漫画阅读：宽度适配屏幕、按原比例上下连续排列，滑动跨页并更新进度；单击画面隐藏/显示顶栏和底栏，顶部阅读工具提供缩略图、书签、模式与全屏；固定底部只保留前后页、页码和细进度条，片单接续在顶栏入口及弹窗中。隐藏菜单时同时隐藏系统状态栏/导航栏；返回键先恢复菜单，重建时保留全屏状态。双指/双击缩放与上下滚动互不触发菜单切换。预读后续三页，屏外解码缓存不超过24MiB；失败页原位重试，恢复阅读时还原页内位置。
- 漫画下载：详情提供下载整本、暂停/继续/重试、离线阅读和管理下载；下载中心与视频共用。临时阅读图页不自动冒充整本下载，已读文件会在主动下载时复用。清理临时数据保留整本下载、收藏和阅读记录。通知点击进入统一下载中心；系统后台时限到达时保留已下载页并暂停，用户可继续。
- 视频播放选择器：清晰度和倍速沿用统一的48dp按钮，文字、16dp箭头和内边距分别占位；背景设置完成后再设置相对内边距，避免文字贴边。窄屏或大字体时，清晰度和倍速移入播放器菜单，保留完整的返回、菜单和全屏触控区。
- 切站：顶栏使用站名与小箭头，窄屏／大字体保留有完整无障碍说明的切站按钮，首页只出现一次站名；抽屉行只保留站名、当前状态和必要的权限提示，移除重复域名，触控区至少48dp。
- 首次切站教程：仅全新安装首次进入首页时，在真实切站入口下显示带指向箭头的深色提示卡，并以浅色填充高亮入口。“打开站点列表”直接展开原有抽屉，“知道了”、返回或点击卡片外可关闭；首次显示即持久记录，后续切站、重建或重启不重复，升级及旧数据迁移用户不弹出。提示不等待联网结果；大字体下卡片随文字增长，空间不足时可滚动。
- ExHentai：抽屉标注账号权限要求；无会话时显示登录门禁及白屏原因，主操作打开官方论坛认证，保留站点设置中的 Cookie 导入入口。权限验证失败的解释持续保留，不能被延迟到达的论坛页面完成回调改写为初始提示。授权验证成功后返回原生浏览。

文字服从系统字体大小；标题与操作不依赖固定高度，大字体参数与筛选可换行，标签测量宽度不得超过扣除左右内边距后的空间。Hero 标题最多两行，瀑布流浏览卡标题最多两行；详情标题完整换行。宽横屏采用较矮全幅 Hero，保留播放与片单空间；旋转时保留当前轮播页。设置值限制最大宽度，为项目名称保留空间。宽屏紧凑密度只在宽度至少840dp且系统字体不超过130%时生效；手机与200%字体沿用原字号，允许详情滚动到主动作。

共享控件使用 Compose Material 3 的 Ripple、键盘焦点反馈、禁用状态和交互语义；顶栏站点入口、底部导航与轮播页码提供明确语义。按钮按压不缩放或改变圆角；选中筛选使用白底黑字与勾号，Dock 使用磨砂填充。清晰度、倍速和其他单选操作使用接近不透明的玻璃底部面板，避免底层文字透入并显示当前选中项；搜索提交使用独立箭头图标，危险确认与输入继续使用圆角对话框。进度条、开关和品牌标识使用 Netflix 红；Hero 播放和共享主动作使用白底黑字，文本操作统一白色。宽屏浏览在840／1024／1280dp采用四／五／六列，跨站与订阅结果在紧凑密度下四列，片库片单双列；不足一行时保留空位，不把最后一项拉宽。

轮播提供暂停/继续按钮；点击页码指示器后暂停自动切换。48dp指示器在窄屏上可横向滚动。页面不可见、触摸探索开启或系统关闭动画时不自动翻页。

封面由 Coil AsyncImage 按布局约束解码，共享24MiB内存与64MiB磁盘缓存；缓存键包含站点，网络请求显式携带所属站点并动态取得现有 Network.client，保留 User-Agent、Referer、Cookie 隔离和系统代理更新。漫画图页的独立预读/缩放缓存不变。流媒体影片名、演示匹配度和参考海报只进入 Debug 玻璃预览与 AndroidTest APK，用于可复现原生截图，不进入 Release APK。Debug 预览用于预先验证视觉，生产页面已复用同一设计方向，两者入口与组件保持独立。

本轮采用“暗室玻璃影院”方向：银幕、烟熏玻璃与磨砂实体三层材质，字体继续使用系统 sans。触控和语义参照 [Android 原生无障碍规范](https://developer.android.com/guide/topics/ui/accessibility/views/apps-views)。

## 动效与范围

原生 Ripple 反馈按压，Dock 状态约200ms过渡，页面首次进入160ms淡入，信息展开箭头180ms反馈；遵守系统动画开关。首页轮播每6.5秒切换，支持封面左右滑动和指示器直接切换；页面不可见、触摸滑动或系统关闭动画时停止自动轮播。加载使用细环、播放三角与低亮度光晕，旋转周期2.8秒、呼吸周期3.6秒，仅在可见且系统允许动画时运行。首次打开显示完整加载场景，播放中缓冲只覆盖画面；阶段由真实连接、准备、缓冲与就绪状态驱动，不显示模拟百分比，就绪后220ms淡出，失败立即退出。悬浮感来自材质、按压和滚动，不使用永久循环漂浮。网络设置统一说明系统代理/直连策略，不再提供 Host/IP 或应用内代理开关；签名、播放引擎、下载服务和数据迁移规则不变。

## 2.2.6 无描边控件

主要按钮使用原生 Button，次级选择器使用 FilledTonalButton，保留 ripple、禁用语义和明显的键盘焦点填充。筛选项选中后使用浅底、深字及勾号；选择面板使用整行填充与右侧勾号，不再堆叠空心圆圈。输入框正常状态使用实心填充，无外框和底线，错误提示仍有文字与颜色。开关由整行提供 Switch 语义，轨道无描边。大字体不缩小文字，按钮可增高/换行，筛选胶囊减少横向留白。宽屏缩小只作用于可见控件和文字，外层通过 `minimumInteractiveComponentSize` 保留触控区，溢出按钮的可见背景放在内层。真实截图与验证见 [无描边调整记录](dev/borderless-ui-2026-11-05.md)；本轮大屏证据位于本地 `.oil-ui/large-screen-density/`。

写真默认逐图翻页并适配完整图片，保留用户保存的阅读模式；漫画默认连续阅读。API 31+ 浮动控件采样内容层，API 33+ 小幅边缘折射，API 24–30 或减少透明效果时用实底；播放器 SurfaceView 使用深色半透明控制材质。
