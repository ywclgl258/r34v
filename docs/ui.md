# R34V 界面规范

目标是让用户从完整封面迅速进入观看，并容易回到上次进度。参考 Netflix Android 的内容层级和横向浏览，沿用 R34V 数据与原生播放行为。

## 视觉

| 用途 | 规范 |
| --- | --- |
| 画布 / 表面 | #000000 / #141414 |
| 主要文字 / 次要文字 | #F3F3EF / #A0A0A0 |
| 品牌、进度、开关 | 珊瑚红 #FF5964 |
| 主播放 / 次操作 | 暖白实底黑字 / 描边或透明底 |
| 标题 / 分组 / 正文 / 元信息 | 22sp / 18sp / 14–16sp / 12sp |
| 内容边距 / 间距 | 16–18dp / 6、8、12、16、24dp |
| 封面 / 控件圆角 | 8dp / 6dp；筛选为胶囊形 |
| 点击区域 | 至少44dp，底部导航至少64dp |

黑底固定，不使用宣传截图外侧红色渐变。完整16:9封面承担视觉主体，标题与播放动作紧随其后，不使用伪竖版海报、定时轮播或自动预览。保持图片原有数据来源。

## 页面与状态

- 首页：热门/最新/高分入口、单一精选、继续观看和最新片架；列表仍通过“查看全部”分页加载。观看卡显示进度和剩余时间，更多菜单可移除记录。
- 导航：首页/发现/搜索/片库固定。下载和设置位于稳定的顶部入口；二级列表延续所属导航状态。
- 发现：热门榜突出，最新/高分/为你推荐为轻量入口，分类、角色作品和作者索引集中排列。
- 搜索：视频/标签/作者范围可见；键盘搜索与搜索图标直接提交；返回结果前的范围和关键词保留，最近搜索可清空。
- 片库：观看/收藏/下载三类任务；收藏下保留视频/角色/作者/标签。现有历史、收藏与下载存储格式不变；视频收藏可通过更多菜单取消。
- 播放：画面优先，完整标题、参数、收藏下载依次分层。简介、标签与评论可展开；相关视频为双列16:9。“重新播放”在更多菜单，错误时显示重试。状态文案同步播放/暂停。
- 设置：连续的灰黑分组，触控行随文字高度扩展。空态说明下一步，网络/解析失败保留重试入口，离线列表明确标记缓存。

文字服从系统字体大小；标题与操作不依赖固定高度，大字体参数与筛选可换行。片架露出下一张表示横向可滚动，浏览卡标题最多两行；详情与精选标题完整换行。

## 动效与范围

原生 Ripple 反馈按压，页面首次进入160ms淡入，信息展开箭头180ms反馈；遵守系统动画开关。不引入循环吸引注意的动效。签名、直连、代理、播放引擎、下载服务和数据迁移沿用已验证路径。
