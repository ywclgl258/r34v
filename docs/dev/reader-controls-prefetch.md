# 阅读全屏、连续预读与紧凑控件

2026-11-04，2.1.6 / 32。

## 阅读菜单与全屏

`ComicStripView` 将 `ZoomPageView` 的单击回调交给 `GalleryActivity` 切换菜单。使用单击确认事件，双击缩放、双指缩放与滚动不切换菜单。顶栏保留48dp全屏入口；进入全屏时隐藏顶栏、底部页码/进度条以及系统状态栏和导航栏，保留挖孔安全区域。再次单击恢复菜单；全屏下返回键先恢复菜单，再返回画廊详情。

菜单切换前记录页码和页内偏移，布局改变后恢复锚点；活动重建保存菜单状态与阅读位置。全屏不强制改变设备方向。

## 连续预读

当前页就绪后，预读后面最多三页，并随当前阅读位置移动窗口。可见页和预读复用同一个页状态与读取任务，避免滑到已预读页时再次请求；可见/跳页目标优先，最多两个并发读取。跳转与离开阅读器时取消不再需要的请求。

解码图像由窗口统一拥有，保留可见页和当前锚点；额外屏外图像总预算24MiB，超过时回收较远图片，已预读的磁盘缓存仍可快速解码。成功预读只更新缓存，不推进阅读历史。失败页不自动反复请求，到达该页时可单独重试。沿用256MiB磁盘图片缓存和6百万像素单页解码限制，不提供整本下载。

## 语言与视频按钮

`GalleryLanguageBar` 用单个水平滚动容器放置四个短标签，整行48dp，取消单独标题；向下滑动收起，上滑及回到顶部显示。收起状态在切站/换页时重置；选中的语言仍按站保存。

`choiceAction` 的原问题是先设置内边距再替换背景，背景的空内边距覆盖文字留白。现在先设置单层背景，再设置相对内边距，箭头固定16dp并留10dp间距；保持清晰度和倍速原有选择行为，并补充控件用途的无障碍描述。
