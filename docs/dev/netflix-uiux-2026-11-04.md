# Netflix 风格原生 UI/UX 重做

版本：2.2.1 / 35。基于当前工作区已经完成的 Compose 迁移继续修改，未回退或覆盖其余未提交成果。用户要求纯黑、Netflix 红、较小字体、柔和按钮、透明渐变与海报片架，并提供玻璃卡片参考图。

## 实现

- 首页由普通轮播和双列视频列表改成全幅 Hero、继续观看、人气 Top 10、高分和最新更新横向片架。Hero 正常竖屏约占屏高59%，图片延伸到顶栏下，顶部暗化、底部渐变至纯黑。
- 影片类型/真实榜单标记、白底播放按钮、半透明片单按钮叠加在渐变上。片单按钮随真实收藏状态即时更新。手动选择页码暂停轮播，保留暂停/继续、生命周期与系统动画/触摸探索约束。
- 海报图像120×180dp，圆角5dp；片架水平边距16dp、卡片间距8dp。最新内容在固定榜单之后追加，保留分页和“查看全部”列表入口。
- 栏目标题18sp，页面标题22sp，正文13–14sp，辅助信息11–12sp，Hero 30sp。控件不靠大字体和粗边框制造层级，触控区保留48dp。横屏降低 Hero 高度，200% 字体扩展高度并允许滚动。
- 顶栏使用渐变透明底、品牌标识、站点下拉、搜索和头像设置。底部导航改为轻量图标/文字及细红选中标记。发现、片库、搜索与设置共用柔和圆角和克制的透明叠层/边缘高光；小号文本操作使用白色。
- 图片统一改用 Coil 3.3 AsyncImage，依据实际约束解码。各站 loader 共用24MiB内存和64MiB磁盘缓存，缓存键包含站点；Call.Factory 每次读取现有 Network.client，并绑定所属 SiteContext，保留 Referer、User-Agent、会话隔离和代理变更能力。漫画 ReaderBuffer 保持原有图页预读/缩放路径。
- 搜索提交先清除输入焦点，再隐藏键盘，减少迅速返回时被键盘拦截的情况。回归测试等待实际 UI 完成再发送返回，首页定位改为可见 Hero，取代已移出首屏的旧列表标题。
