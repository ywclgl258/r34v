## 边界

API 24–32 未启动对应系统进行运行实测，版本降级依据代码保护和静态检查；签名分段验证不代替低版本 UI 实测。设备测试使用中性来源适配器和图页；正式包不含 AndroidTest 适配器，未据此声称全部真实站点实时可用。UX 中近黑图页为深灰测试材料，失效示例链接未作为产品渲染问题处理。Windows headless 模拟器一次 0xc0000005 退出保留为主机证据；换用 swangle 会话后完成最终设备回归，不声称性能结论。

本地完整日志、结构化结果、独立 UX 报告和截图位于 `dist/verification-2.4.0`。正式包及校验文件位于 `dist`。以上为本地交付时的验证；用户随后已授权提交、推送及上传，发布入口见 [v2.4.0](https://github.com/ywclgl258/r34v/releases/tag/v2.4.0)。

## 发布前 CI

首轮推送的单测、Lint 与开发包构建通过；API 24 和 API 36 各运行 47 项回归，均为 46 通过、1 失败。失败集中于同一瀑布流尺寸断言：新封面舞台使首排卡片在较短视口中被裁剪，旧测试比较可见区域高度。测试改为先滚动到卡片并比较未裁剪布局尺寸，保留不同封面比例的断言；随后在 API 36 的 360×640dp 视口复跑该用例通过。修正只涉及测试，正式 APK 不变。后续 CI 结果以 [Actions](https://github.com/ywclgl258/r34v/actions/workflows/build-apk.yml) 对应提交为准；CI 缺少固定发布密钥，正式包使用上述本地固定签名构建产物。
