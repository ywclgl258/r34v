# 跨站搜索与标签订阅修复核验

日期：2026-11-07。状态：功能修复及专项验证完成，提供开发版试用；未生成正式更新，未提交、推送或发布。

## 原因与修改

- **搜索范围**：`MainActivity` 在未保存来源选择时回退为当前站点，导致“多个站点”并不天然等于全部站点。现在由适配器的 `Capability.SEARCH` 统一列出可搜索来源，首次默认全选；用户已有自定义子集保持不变，来源对话框提供“全选”。
- **订阅入口**：订阅存储、管理、标签页订阅按钮和更新收件箱一直存在，但管理入口不明显。片库和订阅更新页增加明确的“标签订阅”入口，继续复用 `SubscriptionScreen`。没有删除、迁移或合并用户的标签订阅；标签收藏与标签订阅仍是不同数据。
- ExHentai 未登录时仍显示权限提示，不把未查询或失败站点当成搜索成功。每站请求继续受现有并发预算限制。

## 未关闭的独立阅读器问题

回归中发现 `OptimizationIoTest.scrollingCoalescesHistoryWritesAndBackFlushesTheFinalPosition` 间歇失败，包括 `ReaderBuffer.window` 的缓存迭代 `NoSuchElementException`，以及返回时阅读记录尚未写回导致的空记录。单测曾通过，随后也复现失败，不能把该问题称为已消除。

此问题与本次搜索／订阅改动没有直接代码关系，本轮未修改阅读器实现，也未掩盖其失败。准确的调度根因尚未在本轮范围内关闭，需要单独处理。由于这一项未关闭，本轮不生成正式签名更新包。
