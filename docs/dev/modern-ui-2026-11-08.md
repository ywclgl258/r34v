# 原生界面现代化 · 2026-11-08

后续按用户授权随 **2.6.0 / 46** 提交、推送及正式打包；发布验收另见 [2.6.0 记录](verification-2.6.0.md)。下文保留本轮开发阶段的证据与开发包身份。

本轮按用户“优化界面，现在的前端 UIUX 不够现代”实施。保留 Kotlin/Compose 原生 Android、黑底与 Netflix 内容优先方向，延续此前已完成的新功能；没有引入账号、推荐服务、依赖或数据迁移。

## 界面与行为

- 底部导航改为固定黑底四入口，红色位置指示保留 220ms 过渡。内容使用 Scaffold 实际底部安全区，不再依赖给悬浮胶囊预留空白；200% 字体末尾入口可以正常点击。
- 首页突出真实封面、作品名、进度和继续操作；视频、漫画、写真分别使用观看、阅读、浏览文案与图标。大字体时文案移到封面下方。稍后看与订阅更新使用列表入口，更新数量包含保存搜索未读。
- 已完成的作品不再从稍后看片单回落到首页“继续观看／阅读”主卡，仍可在用户片单中找到。
- 播放主按钮白底、小圆角；共享按钮、选择器、封面、阅读控制层统一收紧圆角。设置换为齿轮，记录与更新使用时钟、铃铛。阅读器／播放器覆盖媒体的暗色控制层保留模糊与减少透明效果设置，去掉玻璃描边、阴影和折射。
- 主界面移除不再被导航使用的背景录制层。不会为静态黑色导航录制、采样页面。
- 片库四个快捷入口在大字体／窄屏重排为两列。修复手机单列片单与单图收藏错误补半列空白的问题；空片单显示明确图标与空态，导入与链接改为可读列表入口。大字体片单计数按完整短语分行。
- 搜索框置顶，范围和类型随后；筛选的作用范围仍可在高级筛选及结果中查看。保存搜索、跨站筛选、导入和已有阅读／播放功能保留。
- 文案改为“我的稍后看”“站点精选”，避免暗示个性化推荐。测试素材中的百分比“匹配”替换为明确的示例评分；业务始终显示适配器提供的真实 rating，未新增推荐计算。

- 375dp／200% 字体复验两项通过，覆盖空首页／片库、三种媒体切换、阅读翻页与继续操作。首次失败证实末尾入口被旧浮动导航遮挡；改用真实 Scaffold 底部安全区后通过。
- API 24 手机八项通过，包含片库／导入入口、三种媒体、减少透明效果、循环、阅读设置、图片导出与搜索更新。
- 独立结构审查：`/root/ui_structure_review`，补齐媒体语义、大字体重排及真实空态规则后通过。
- 独立视觉审查：`/root/ui_visual_review`，最终 **8/10**。按反馈精简片库重复层级、空态与片单文案。最终新路径截图四个导航入口完整；评审撤回旧预览造成的导航缺项判断。静态审查不作为动效／交互验证。
- 人工 UX 审查：`/root/ui_ux_review`。初次模拟器退出；第二次发现人工点击由测试托管时钟阻塞。已为可选 liveReviewFixture 添加持续 UI 时钟推进，并在截图前显式等待 Compose 空闲。上述运行保留为环境／测试取证异常，不计作产品验收通过。
