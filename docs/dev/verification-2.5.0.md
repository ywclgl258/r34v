## 首批功能

已实现计划首批 16 项：

- **搜索与发现**：F01 高级组合筛选、F02 标签补全与条件编辑、F06 自定义发现频道。来源查询与仅筛选已加载结果在界面分别说明；条件、保存方案、频道排序／隐藏可恢复并进入备份。
- **播放**：F08 简介／评论时间戳、F09 时间书签与分组备注、F10 按来源的倍速、长按倍速、快进步长和手势范围。时间范围按真实时长校验，清晰度切换不删除书签。
- **阅读**：F13 音量键翻页、F14 自动翻页、F15 作品级显示覆盖。自动推进以图片成功加载为条件，触摸、末页和后台暂停；支持音量方向、长按首尾页、适配、起始位置、裁边和双页封面规则。
- **图库**：F19 Iwara 原生图库、F20 单图收藏与跨集画墙、F21 图集幻灯片。`/images` 与 `/image/<id>` 使用独立内容类型，图库与旧视频身份不冲突；混合视频文件不进入图片解码路径。幻灯片与自动翻页互斥，切后台停止。
- **下载管理**：F31 图集队列优先级、F32 分组／搜索／排序、F33 页范围下载、F36 完整性检查与缺页修复。部分保存不写整本完成标记，有效页可离线打开；修复只重取缺页／坏页。

A 组下载恢复同时落地：视频删除代次与刷新取消、错误分类、有限退避、`Retry-After` 秒数／日期、合法图源单次刷新、任务详情与网络／权限／存储恢复动作。阅读进度在退出生命周期时同步提交，避免返回后读到空记录。
