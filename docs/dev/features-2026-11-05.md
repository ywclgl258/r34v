核心闭环：搜索 → 加入稍后看/合集 → 播放或阅读 → 保存进度/完成状态 → 备份恢复。每阶段只修改其生产路径和必要验证；发生错误先修当前阶段，不扩大功能。

备份只使用用户选择的文件，合并收藏、订阅、历史、书签、片单、设置；原站账号重新登录，媒体文件继续由现有下载位置管理。各站同 ID 不合并。后台订阅推送、云同步、跨站作品模糊去重不属于已确认方案。

## 已实现的使用路径

- 搜索 → 多个站点 → 选择来源 → 提交关键词。按视频/漫画/写真筛选，各站独立加载、分页与重试，最多三个并发请求。更换查询取消旧请求，返回或重建保留状态；分站语言、屏蔽词变化会使查询失效。EX 权限缺失只影响该来源。按 `site:id` 去重，不进行跨站同名作品合并。
- 作品菜单/详情 → 稍后看、加入合集；首页“我的片单”现对应稍后看。片库 → 片单可管理自定义合集、排序、完成状态和来源/类型筛选。以前版本首页按钮保存的收藏仍在原收藏页，不删除或自动改写。
- 片库 → 订阅 → 更新收件箱。首次成功的实时响应为每个标签建立基线；失败和离线快照不推进基线，新订阅不把历史列表全部标成未读。保留每标签最近 1000 个见过的 ID、每站 1000 条收件箱记录；多标签作品去重，打开作品或手动操作可标记已读。更新在用户进入/刷新订阅页时检查，不包含后台推送承诺。
- 阅读器顶栏 → 阅读模式、页码书签。保留原上下连续与缩放，新增向左/向右翻页及横屏双页；模式按站点保存，书签按站点/作品/页码保存。双页在竖屏降为单页，切换模式和重建按逻辑页恢复；原连续模式仍保留页内偏移与有界预读。
- 片单 → 批量下载可多选作品，视频采用设置中的默认清晰度，图集整本加入。下载中心 → 批量管理可选任务暂停/继续，添加失败逐项列出，停止添加不会撤销已经加入的任务。
- 下载中心 → 任意网络/仅非计费网络。视频使用 Media3 Requirements，图集使用同一系统计费状态判断；网络不满足时保留队列并取消在途图集请求，不把等待误写为用户暂停。系统结束进程或限制后台服务时，图集可回到应用后恢复；没有新增常驻等待服务。
- 播放器 → 更多播放操作 → 锁定画面、定时暂停、画中画。锁定时屏蔽原手势并保留解锁入口，返回先解锁。定时支持 5/15/30/60 分钟、自定义 1–180 分钟及关闭，重建保留截止时间。Android 8+ 且设备支持时显示手动画中画，进入后只显示视频，返回保持同一播放器，真正停止可见后仍释放。
- 设置 → 备份与恢复。导出使用系统文件选择器；恢复先选文件、输入密码、解密预览，点“合并恢复”才写入。按来源和记录身份合并，观看/阅读使用时间较新的记录；原有片单顺序保留并追加缺失作品，设置采用备份值。一次 SharedPreferences 提交写入，不清空会话和下载索引。

## 数据与实现边界

新片单、书签、阅读模式及收件箱位于 `personal_library_v1`，使用不可变快照和缓存读，避免封面列表重复解析整份数据。旧收藏、历史、订阅及媒体格式沿用。新增界面拆在 `ComposeCrossSearch`、`ComposeCollections`、`ComposePagedReader`、`ComposeBackup`，入口复用 MainActivity 和现有播放器/阅读器。

备份格式 `R34VBK01` / schema 1：用户密码经 PBKDF2-HMAC-SHA1 600000 次派生 AES-256 密钥（兼容 Android 7），每份新建 16 字节盐与 12 字节 IV，AES-GCM 认证覆盖文件头和密文，明文负载最多 16 MiB。只导出类型明确的收藏、订阅、历史、片单、书签、屏蔽词与允许的设置。解密/格式验证完成前不写入；密码、账号 Cookie、本机密钥、下载位置与媒体文件不在负载中。系统文件选择期间仅将加密临时文件和其标识保留于应用缓存，完成/取消后清理，密码不写入 Bundle。

画中画首轮暴露窗口变更重建：小窗出现详情、返回丢失实例。修复为声明 `smallestScreenSize|screenLayout` 配置变化并从系统状态初始化小窗模式，补充小窗隐藏详情与保持同一引擎断言。旧存储权限测试在 onPause 后立即返回，会早于系统权限窗口就绪；按实际活动窗口等待后再返回，生产存储逻辑不变。

最终全量回归还复现原登录页的回调竞争：手动验证反馈可能在绘制前被论坛加载完成/失败回调覆盖。用独立状态保留明确验证反馈，重新登录或取得身份时再退出该状态；补充实际 WebView 完成回调不覆盖反馈的断言，TLS 校验与权限验证逻辑不变。

工程参考：沿用 `ui-ux-pro-max` 的 Compose / 触控规则及现有界面规范；Library 路由 `orchestrate-project-blueprint`，快照 2026-08-18，仅加载 ST-A0，无新增设计依赖。平台能力核对 [Android 画中画](https://developer.android.com/develop/ui/views/picture-in-picture) 与 [Media3 下载](https://developer.android.com/media/media3/exoplayer/downloading-media)。
