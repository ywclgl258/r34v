# 首次站点切换教程

2.2.0已将提示卡与真实抽屉迁移到Compose DropdownMenu和ModalNavigationDrawer，一次性标记与新旧用户判定保持不变。以下记录2.1.7的原始交互合同，旧PopupWindow实现已删除，当前实现与验收见 [Compose重构](compose-migration.md)。

2.1.7 / 33 为全新安装用户增加一次性的首页提示，保持原有紧凑站名与箭头布局。提示卡指向真实的站点切换按钮，高亮按钮边框，说明可切换视频站和漫画站，以及收藏、历史、下载按站保存。

- “打开站点列表”关闭提示并展开原有 `SiteSwitcher`，后续选择站点走原有切站流程。
- “知道了”、系统返回或点击卡片外均关闭提示。显示即记为已看过，重启、切站、Activity 重建不会再显示。
- 提示不等待列表网络请求，首次离线也可直接打开站点列表。仅在首页且 Activity 已恢复、按钮已布局和附着、抽屉未打开时显示。
- 离开页面、暂停、配置变化或销毁时关闭原生 `PopupWindow`，恢复按钮原有背景与内边距。
- 深色圆角卡片宽度不超过320dp，窄屏保留边距。文字服从系统字体大小；可用高度不足时通过原生 `ScrollView` 阅读并操作。

## 一次性状态

`LibraryStore` 在写入迁移标记之前判断安装状态：原生偏好与旧 Flutter 偏好均为空时，写入全局 `site_switch_tutorial_seen=false`；任一已有数据则写入 `true`。已有标记不覆盖，因此首次首页尚未显示时重启仍可提示，已显示后不再提示。此标记不按站点隔离。

显示前通过 `consumeSiteSwitchTutorial()` 同步提交 `true`，提交成功才显示。不在用户操作后才记录，避免关闭、进后台、重建或进程退出造成重复；普通关闭算作看过，没有二次确认。

## 验证

`SiteSwitchTutorialTest` 使用中性的本地列表响应，覆盖全新/升级/旧数据迁移资格、待显示时重建存储、仅消费一次、打开真实抽屉并切站、关闭和返回、重启、Activity 重建，以及首次离线显示。现有 UI 测试通过 `ExistingUserRule` 明确以已有用户启动，不影响各自目标流程，并在结束后恢复原状态。

设备验证及构建结果记录于 [HANDOVER.md](HANDOVER.md)；截图和本地APK位于仓库忽略的 `dist/site-tutorial-2.1.7/` 与 `dist/`。用户在本地验收后明确授权提交、推送与上传，发布版本为 [v2.1.7](https://github.com/ywclgl258/r34v/releases/tag/v2.1.7)，提供标准APK、仅Android7/8已装2.0.0专用兼容APK及SHA256摘要。
