## 可使用的功能

| 功能 | 入口与行为 |
| --- | --- |
| 片单搜索 | 打开稍后看或合集，点击标题旁的搜索图标。按已保存的作品标题和来源名称／标识匹配；忽略大小写，多个词同时匹配。只检索当前片单，不发送站点请求。查询和搜索展开状态可跨 Activity 重建恢复。 |
| 筛选与排序 | 原“筛选”面板保留完成状态、媒体类型、来源，并增加最近 7／30／90 天加入，以及手动、最近加入、最早加入、标题顺序。显示排序不改写手动顺序；顺序播放和离线准备使用当前结果。上移／下移只在手动顺序且无筛选条件时提供。 |
| 合集备注与置顶 | “合集设置”编辑名称、最多 1000 字备注及置顶。稍后看可设置备注／置顶／封面，但不能改名或删除。保存统一提交，取消放弃草稿。片库优先展示置顶合集，同组保留原顺序；备注预览最多两行。 |
| 自选封面 | 在合集设置中从本合集作品选择封面，或恢复自动封面。只存来源＋作品身份，复用已有封面；不会额外复制图片。移除选定作品后自动回退，不丢失备注和置顶状态。 |

搜索输入时收起设置、离线准备和顺序播放等次要操作，给结果留出空间；键盘“搜索”收起键盘并清除输入焦点。无匹配时提供“清空条件”，真正空片单保留去搜索入口。

本轮不把 F39/F40 整体标记完成：未新增作者／真实标签索引、收藏总库检索或自定义展示布局。没有接入外部服务、账号、额外依赖或新媒体引擎。

## 数据与备份

`Shelf` 增加备注、置顶、封面作品键和元数据修改时间，保留零参默认构造。旧 JSON 缺少新字段时得到空备注、不置顶、自动封面和时间 0；原条目、完成状态、加入时间和手动顺序保留。

备份校验限制备注长度，核对封面属于当前合集并验证修改时间。合并时使用更新的合集元数据；时间相同保留本机值。作品仍按原规则合并去重、保留本机手动顺序和更早的加入时间。主动清空备注／取消置顶／恢复自动封面也更新修改时间，避免旧备份再次覆盖。实际加密备份恢复测试验证了新字段，以及目标设备的原凭据仍保留。
