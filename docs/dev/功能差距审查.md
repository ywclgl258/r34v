# 原站功能审查

对着 rule34video.com 实抓页面逐项盘点，标记**已实现 / 缺失**。

审查方式：抓首页、列表页、视频详情页、`top-characters`、`top-model`、搜索页的真实 HTML，
提取导航链接、表单字段、按钮 class、卡片结构，再对照 `lib/` 现有实现。

---

## 一、缺失的功能

### A. 排行/索引类页面（整页缺失）

| 原站页面 | 内容 | 我们 | 影响 |
|---|---|---|---|
| `/top-characters/` | **角色排行榜**（含点赞数） | 无 | 「发现」页只有分类，没有角色榜 |
| `/top-model/` | **作者排行榜**（jackerman / derpixon / nyl…） | 无 | 找不到热门作者 |
| `/tags/` | **标签总索引**（可浏览全部标签） | 只有分类索引 | 无法从「标签」入口开始逛 |
| `/characters/` | 角色总索引 | 无 | 同上 |
| `/models/` | 作者总索引 | 无 | 同上 |
| `/for-you/` | 个性化推荐（需登录） | 无 | 不做（依赖登录） |

**这是最大的一块缺口。** 我们的「发现」页只有榜单 + 分类，而原站有五种索引页。

### B. 视频详情页的交互

| 功能 | 原站实现 | 我们 | 说明 |
|---|---|---|---|
| **点赞 / 点踩** | `button_rate rate-like` + `data-vote` | 无 | 需要登录态，只能显示不能提交 |
| **下载视频** | 每档清晰度一个 `tag_item_download` 直链 | 无 | 有直链就能下，**不需要登录** |
| **分享** | `js-vp-share` 按钮 | 无 | 分享链接/复制标题 |
| **评论** | `#tab_comments` 评论列表 + 发表 | 无 | 只读列表可行，发表需登录 |
| **标签投票** | 每个标签旁 `upvote/downvote` | 无 | 需登录 |
| **相关视频** | 已有 | ✅ 已做 | |

### C. 浏览体验

| 功能 | 原站 | 我们 | 说明 |
|---|---|---|---|
| 排序（5 种） | post_date / video_viewed / rating / duration / pseudo_rand | ✅ 已做 | |

### D. 我们做了但原站没有的（差异项，需确认是否保留）

- 本地缓存（原站靠浏览器缓存）
- 续播进度（原站记 cookie）
- 收藏分类管理（原站收藏需登录）
- 播放器音量/倍速记忆（原站播放器是第三方 embed）

这些是客户端化的收益，建议保留。

## 二、原站依赖登录、我们做不了的部分

| 功能 | 原因 |
|---|---|
| 点赞/点踩 | 需要账号 session |
| 收藏（站内） | 需要账号 |
| 发表评论 | 需要账号 |
| 标签投票 | 需要账号 |
| `/for-you/` 推荐 | 需要账号 |
| 上传视频 | 需要账号 |

**这些可以"只读"或"用本地收藏替代"**：
- 点赞数：详情页已能解析显示（`⊙ 1.1K`），只是不能提交
- 收藏：已用本地收藏替代，体验更好（不用登录）
- 评论：可以只读展示

## 三、建议的实现顺序

按「对使用价值 / 实现成本」排序：

### 第一优先（成本低、价值高）

1. **下载视频** — 直链已有，加个按钮就行。不需要登录
2. **标签索引页 `/tags/`** — 复用现有 `fetchTags()`，换个 UI（按首字母分组或热度排序）
3. **作者/角色索引页** — 同上，加 `fetchModels()` / `fetchCharacters()`
4. **角色排行榜 + 作者排行榜** — 抓 `top-characters` / `top-model`，复用列表卡片

### 第二优先（中等成本）

5. **评论只读展示** — 解析 `#tab_comments`，显示在详情页底部
6. **分享** — 复制链接/标题，成本极低
7. **RSS 订阅最新** — 已有 fixture，解析 RSS 做「订阅」入口

### 第三优先（成本高或价值有限）

8. 标签投票、点赞提交 — 需登录，只能做只读计数
9. `/for-you/` — 需登录

## 四、我的判断

**最该补的是「发现」页。** 现在它只有 3 个榜单入口 + 36 个分类方块，而原站有：
- 角色榜、作者榜（带排名的排行榜，不是普通列表）
- 标签、角色、作者三种总索引

这让「不知道看什么、想随便逛逛」的路径几乎不存在——只能搜索或看最新。

**其次是下载。** 每档清晰度都有直链，`tag_item_download` 就是一个普通 `<a href>`，
不需要登录也不需要特殊 header。加一个按钮 + 写文件就能用，而这是很多人真正需要的功能。
