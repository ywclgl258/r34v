# 2026-11-04 UI/UX 打磨

在当前七站原生 Kotlin 工程上继续使用 `ui-ux-pro-max`，保留黑底，以内容、播放动作和清晰的导航层级为中心。设计规则统一记录在 [界面规范](../ui.md)。

## 实现

- 调整次要文字、强调文字和可操作描边，避免用深红色承担小字号信息。共享按钮、图标和阅读进度触控区至少48dp，按压采用原生 Ripple，键盘焦点有独立描边，禁用状态降低强调。
- 顶栏标题单行省略并保留下拉箭头，下载/设置维持稳定触控空间；底部当前入口增加灰底容器及加粗文字，并保留原生选中状态和按钮语义。
- 筛选和标签使用统一圆角、8dp间距，测量时扣除内边距，长标签和大字体能够在容器内换行。
- 首页轮播增加暂停/继续，手动翻页保持用户暂停；窗口失去焦点或开启触摸探索时停止自动轮播，不切换屏幕外的封面。600dp及以上宽屏并排展示完整封面和信息，旋转保留当前页。
- 搜索增加当前站点说明、一键清除和空提交提示；保留关键词、范围及返回行为。片库空态区分观看、阅读、收藏、下载并提供“去发现”；加载失败给出重试动作。
- 封面更多按钮视觉缩为32dp并保留48dp点击区域；设置值限制宽度；阅读器跳页/拖动进度和播放器返回按钮统一触控区。
- 修复官方登录的延迟论坛回调覆盖权限拒绝说明，补充确定性的回归断言。轮播交互测试先暂停自动翻页，并等待旋转后的实际布局完成再注入手势，避免系统转屏和6.5秒计时竞争。
