# 漫画语言筛选与连续阅读

2026-11-04，覆盖 E-Hentai、ExHentai、nhentai、Hitomi。

2.1.6 后续更新：语言栏现为单排且随滚动收起，条漫增加隐藏菜单/全屏与后续三页连续预读，替代下方2.1.5的常驻筛选栏和仅附着页加载策略。见 [后续说明](reader-controls-prefetch.md)。

## 语言与分页

`FeedRequest.language` 提供 ALL、CHINESE、JAPANESE、CHINESE_JAPANESE；旧请求反序列化默认 ALL。选择保存在各站自己的 `gallery_language` 偏好中。首页、发现、搜索和结果页共用常驻筛选栏；切换保留关键词/分类/排序，清空旧游标，重新从第一页读取。离线列表缓存同时区分语言与合并游标。

- EH/EX：首页、分类和搜索使用精确语言标签；中日合并使用 `~language:chinese$ ~language:japanese$`。游标保留原站翻页位置并重新应用当前选择。`f_sfl=on` 避免账号的语言排除设置覆盖显式选择。语法依据 [官方搜索说明](https://ehwiki.org/wiki/Gallery_Searching)。热门页实测忽略 `f_search`，因此按该热门池中各行的语言标签筛选，保留热门顺序。
- nhentai：使用 [官方 v2 OpenAPI](https://nhentai.net/api/v2/openapi.json) 的语言查询。单语言热门仍用 `popular-today`。文档未说明支持 OR；中日合并分别查询中文与日文（后者排除中文避免重复），游标保存两个来源的页码和页内位置。最新按编号归并；热门交替展示两个语言榜单，保留各自榜内顺序。合并页大小24，短时缓存原站分页，避免反复请求。
- Hitomi：单语言首页按48字节范围读取语言索引。中日首页同样只按小段归并两份索引，避免把巨大的日文索引展开为对象集合；类别/关键词查询先求候选，再扫描语言索引取交集。中日是并集，分类与关键词仍是交集。最新保留编号顺序，分类热门沿用原站排行榜；首页合并热门保留两个语言榜的顺序交替展示。

筛选依赖原站语言标签，不从标题中的汉字或假名猜测。缺失语言标注的内容可能不出现在受限语言列表；全部显示保留原有站点行为。用户本地片库不受浏览筛选隐藏。

## 条漫阅读

`ComicStripView` 使用原生 RecyclerView 连续显示全书页数的轻量行。图片按屏幕宽度和真实比例排版；只给附着行请求图片，关闭列表预取，最多两个读取任务并发。离屏/回收/退出阅读时取消请求并释放图片。沿用原有已读页磁盘缓存和6百万像素解码上限，不整本下载。

缩放后的图片接管拖动和双指手势；原比例时把上下滚动交回列表。页码和跳页进度条定位到对应行；失败页显示局部重试，不阻断其他已载入页面。阅读记录新增兼容旧数据的 `offset` 字段，退出、后台、重建时保存当前页与页内偏移。预先加载的相邻页不覆盖当前阅读进度。
