# 三类媒体的 Liquid UI 改版

用户在本轮九项功能实施后，追加要求参考 AndroidLiquidGlass 与 apple-design-skill 全面升级视频、漫画和写真 UI/UX。正式目标仍为 2.4.0 / 42，保留已实现功能、黑底和原生 Android 行为；隐私体验不在范围内。

## 方向与结构

北极星：眼睛先找到内容，手指直接回到上次的位置。内部比较了连续放映、内容检视和片单接力三个方向，选择继续操作优先的第一案；搜索与片库保持适合检视的列表，顺序接续只放在片单流程。独立灰度结构评审通过（`/root/liquid_structure_review`）。

| 页面 | 主角与主动作 | 内容组织 |
| --- | --- | --- |
| 个人首页 | 最近未完成对象，继续观看／阅读／浏览 | 常用搜索、稍后看、全局订阅更新 |
| 视频来源 | 有记录时续播，无记录时真实精选 | 原有榜单和片架；保留自动分页与轮播暂停 |
| 漫画来源 | 书封与阅读位置，继续／开始阅读 | 语言条件、保持原比例的封面网格 |
| 写真来源 | 图集主图，继续／开始浏览 | 图集网格；默认逐图翻页，不显示漫画语言筛选 |
| 详情 | 封面、标题、真实页数和主要打开动作 | 收藏、片单、离线、缩略图和来源元信息 |
| 阅读器 | 清晰图页 | 顶部返回／阅读工具；底部前后页／页码／细进度条 |
| 片库／搜索／下载／设置 | 对象或当前任务 | 稳定实底内容，统一字体、按钮和弹窗 |

56dp 页头与主块高度均为默认或最小值；文本放大时允许增长与换行。底栏四项有文字标签及至少 48dp 目标，栏高随字体增加。320dp / 200% 字体时内容网格降列；840dp 以上片库保留列表详情双栏。内容可滚离悬浮导航，系统返回、文件选择器与 IME 仍按 Android 行为工作。

## 材质与实现边界

采用 [AndroidLiquidGlass 的 Android 1.0.0](https://github.com/Kyant0/AndroidLiquidGlass/tree/1.0.0)，实际依赖为 `io.github.kyant0:backdrop:1.0.0`。该分支匹配现有 Kotlin 2.2 / Compose 1.9 工具链，已编译与 DEX 打包；未为接入最新多平台分支而升级整套工具链。Apache 2.0 许可保留于 APK 资产。

参考 [apple-design-skill](https://github.com/dickwu/apple-design-skill) 的材料、布局、字体、颜色、无障碍与导航资料，并遵循 [Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials) 的内容层／控制层区分。借鉴视觉和交互原则，继续使用 Android 48dp 目标与系统导航。

玻璃仅用于主导航、紧凑顶栏及阅读／播放操作面板。封面、正文、下载任务与分类卡片不折射。只记录可见内容图层，控制层在旁边绘制，避免把控件再次采入自身；深色基底避免未采样区域露出清晰文字重影。

| 条件 | 效果 |
| --- | --- |
| API 24–30 | 深色实材质，无背景记录 |
| API 31–32 | 内容采样与模糊 |
| API 33+ | 模糊和小幅边缘折射 |
| 减少透明效果 | 所有版本使用深色实底，并停止内容层记录 |
| 视频 SurfaceView | 高对比半透明控制材质；不声称采样或折射视频像素 |

主动作统一白底黑字，品牌与进度采用珊瑚红 `#EF4954`；正文采用 14–16sp，辅助信息 12–14sp。主导航选中底随切换移动，筛选状态颜色过渡，阅读控件淡入淡出；系统动画时长设置继续生效。

## 验收记录

模拟器 API 36，真实 Compose 页面与中性测试媒体；测试适配器只在 AndroidTest 进程使用，正式 APK 没有模拟来源。截图中影视封面来自既有测试素材，不代表新增业务推荐或漫画／写真数据。主视口 411dp，另测 320dp / 200% 字体、短横屏与 1280dp 宽屏。

最终默认视口 36 项设备测试全部通过，覆盖九项功能、外部分享、真实系统目录导入、离线扫描路由、三类来源、清晰度／倍速／全屏、锁定／定时暂停／画中画、翻页／双页／书签及加密备份。320dp / 200% 字体和 1280×800dp 三类来源与片库流程均通过；约 811×375dp 横屏验证了三类来源、阅读工具、队列接续和双页，隐藏工具不会移动图页。API 24–32 尚无运行设备，不把静态版本保护与签名校验当作低版本 UI 实测。

独立视觉评审 `/root/liquid_visual_review`：8/10，静态画面无发布否决。已修正其提出的紧凑页头来源缺失、跨媒体时长、重复语言、空搜索区和漫画孤字换行；原视口重新取证。另据平板真实画面，将视频／写真主块改为图文并列，主动作在首屏可见。

独立代码增量检查 `/root/next_feature_code_review`：已修复短横屏完整队列堆叠占满阅读区，以及减少透明效果未纳入备份的问题；队列改用可滚动面板，新增设置已经往返恢复验证。旧响应测试改为验证控件隐藏、图页不位移和系统返回恢复。
