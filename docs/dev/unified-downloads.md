# 视频与漫画统一下载

2.2.2 / 36，2026-11-04。本轮在 Compose / Netflix UI 成果上增量开发。用户已授权提交、推送与上传，发布入口为 [v2.2.2](https://github.com/ywclgl258/r34v/releases/tag/v2.2.2)。

## 使用方式

- 视频详情点“下载”，选择清晰度；原来“缓存清晰度”“完整缓存”等主动保存文案统一为下载，既有 Media3 索引、文件和旧版离线视频原地沿用。
- EH、EX、nhentai、Hitomi 漫画详情点“下载整本”。四站复用各自原有详情/图页协议，下载可暂停、按页继续、失败重试，并保留每本的进度/页数/大小。
- 所有站点的片库均提供“下载”，进入同一下载中心；默认汇总全部站点，可按媒体类型与站点筛选。任务始终显示来源站点，下载、续传与删除仍按所属站点处理。同一作品ID在不同站点不会共用记录或文件。
- 完成后视频“离线播放”，漫画“离线阅读”。漫画离线模式读取持久保存的详情与页码映射，跳页和阅读预读也只访问本机文件，缺页不会偷偷联网。EX在线门禁保留，自己已下载的完整漫画可直接在本机打开。

## 保存与执行

`GalleryDownloadStore` 将每本的状态、已保存页数、总页数、字节数和错误写入独立持久记录；`GalleryDownloadService` 以 dataSync 前台服务执行单本队列，通知直达下载中心。进入后台后继续执行；服务重建或回到应用后恢复未完成队列。系统后台时限到达时暂停并保留进度，不在开机广播中强行启动服务。暂停与删除会等待在途任务取消，避免删除后又写回文件。

整本原始图片位于 `files/gallery-downloads/<site>/<作品ID哈希>`，不参与 `gallery-cache` 的256MiB阅读LRU。每页校验图片尺寸后原子落盘，不为批量下载解码完整位图；完成所有图页及映射后再写完成标记。已读缓存可复用，部分下载可以按页续传；中断页重新获取，其余已保存页不重下。完成下载仅通过用户删除移除。临时播放/阅读数据可在设置清理，保留所有下载、收藏和记录。

实现沿用现有 Network 的系统代理、TLS、User-Agent、所属站点标记和图片页 Referer；没有引入新源站接口或额外登录方式。前台服务类型与超时处理依据 [Android服务类型](https://developer.android.com/develop/background-work/services/fgs/service-types#data-sync) 和 [前台服务时限](https://developer.android.com/develop/background-work/services/fgs/timeout)。使用现有原生服务方案，未引入另一套下载框架。

## 验收范围

新增原生用例覆盖整本落盘、清理阅读临时数据后离线跳到末页且无网络请求、暂停持久化/续传不重下已完成页、失败页重试、在途删除不重建文件、四站相同ID隔离、视频与漫画统一展示、后台下载、系统时限暂停，以及旧版离线文件原地读回/按所属站点删除。另回归站点协议、漫画阅读、视频播放/下载和旧数据迁移。

测试使用原创中性图片与本地视频，不请求真实私有账号或大规模外站内容。真实EX账号下载、Android7/8运行和各源站配额仍需对应环境验证；本地模拟器夹具结果不替代这些边界。最终构建、签名、用例数量和截图证据见本地 `dist/downloads-2.2.2/VERIFICATION.md`。
