## 功能入口与行为

| 功能 | 入口 | 行为 |
| --- | --- | --- |
| A–B 区间循环 | 播放器菜单 → A–B 区间循环 | 分别将当前位置设为 A、B，B 至少晚 1 秒；显示区间并可清除。暂停时不跳转，旋转/重建保留区间。手动跳出区间清除循环；切清晰度后验证时长，失效区间清除。重新打开视频不继承上一会话区间。 |
| 阅读状态栏与屏幕 | 阅读工具 → 阅读状态栏与屏幕 | 可选时间、电量、页码、进度，收起工具时显示；亮度及保持亮屏按来源保存。离开阅读页面恢复系统亮度和默认亮屏行为。 |
| 图片保存与分享 | 阅读工具或图集详情 → 图片保存、分享与 CBZ | 保存/分享当前原图，或输入页码选择多张。单图使用系统创建文件，多图使用系统文件夹选择器；分享使用临时只读 content URI。保留原始文件编码与字节。 |
| 图集 CBZ 导出 | 同上 → 完整 CBZ / 选择页码导出 CBZ | 按数字页码排序，保留图片原文件；本地导入、已下载、缓存与在线图源可用。离线模式缺页会报错，不交付不完整归档。 |
| 保存搜索更新与未读 | 搜索 → 保存搜索更新与未读；或订阅更新 → 保存搜索 | 全部方案或单个方案手动检查，最多 3 个来源同时请求。首次成功建立已读基线；后续新结果未读，打开作品或手动标记后已读。失败、超时、缓存结果不推进基线，详情逐来源显示状态。重命名保留基线，条件变化重置，删除后晚到的响应不能恢复方案。 |

搜索检查各来源当前结果的第一页，支持时使用最新排序；不是后台持续监听，也不承诺覆盖两次检查之间掉出第一页的全部作品。新增状态和阅读设置参与加密备份、校验及合并恢复，旧数据可继续读取。

导出上限为每批 2000 页、原图总计 1 GiB、单图 50 MiB（远程图源沿用现有 24 MiB 限制），单次分享最多 100 张。任务逐页处理、显示进度并可取消；任务状态随 Activity 重建保留，进程结束后需重新导出。分享临时文件保留供接收应用读取，后续导出会清理超过两天的临时目录。保存失败或取消会尝试移除新建文件；目标提供方拒绝删除时明确提示手动清理。
