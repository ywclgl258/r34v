# UI 结构重构与开发包验收

日期：2026-11-08。基于正式版 2.6.0 / 46 的本地开发修改，未提交、推送或发布；正式包名、版本、签名配置与继承链未变。本次交付为独立安装的开发包。

## 改动

- 个人首页：新增“全部 / 视频 / 漫画 / 写真”筛选；全幅主封面融入黑底，标题、真实进度和白色继续按钮集中展示。稍后看用真实封面横排，管理入口位于内容之后。已完成作品不作为续播主角。
- `PersonalFeature` 单独封装主作品展示，复用现有图片、按钮和媒体路由。漫画完整显示书封，窄屏及大字体将封面与文字分开；宽屏左右排布，按实际可用宽度适配。
- 片库：顶栏明确显示“我的片库”，快捷工具减轻视觉重量；我的片单、智能片单、本地内容只展开当前分区。选择可跨 Activity 重建恢复。收藏、下载、订阅、单图收藏、导入及链接打开入口保留。
- 搜索：当前／多个站点使用统一标签；减少重复来源说明，移除无切换作用的“关键词”单选项；有有效条件时才出现保存按钮。已保存搜索显示名称和查询内容。
- 片单：从首页直接进入整理页，取消重复导航区。上移／下移后等待数据更新并将目标作品滚到可见位置，能立即核对新顺序。
- 共享标签具有 Tab 选中语义和至少 48dp 触控区域。保留四项固定底栏、黑底、白色主操作与红色强调色。

没有新增外部服务、素材下载逻辑、依赖、数据格式或生产接口。测试封面只在 AndroidTest 夹具中使用。

ModernUiTest 的六项为：空态入口、收藏身份、完成作品排除、媒体筛选、片库分区恢复、排序目标保持可见。人工走查用 `liveReviewFixture` 默认跳过，不计入自动回归通过数；最后单独开启取证并正常退出，恢复夹具原数据。

视觉审查后压缩了片库工具区、去掉搜索重复说明和空条件保存入口、缩短首页主封面与片架间距。UX 发现的片单固定头部过高与排序目标离开视口已修复，新增排序回归在 API 24 / 36 均通过。最终首页与宽屏实际截图已复核；未对修正稿重新打视觉分。

### 保留的失败与复测记录

- 初始 API 36 模拟器进程中断，基线批次未完成；降低模拟器资源配置后重新启动完成上述专项，未把中断批次记为通过。
- API 24 首次最终批次为 8 通过、1 跳过、1 失败：高级搜索在应用条件／保存操作处超时。原测试单独复测通过；随后增加主页就绪、收起键盘和滚动到保存按钮的步骤，连续两项搜索流程通过，未更改业务逻辑以绕过失败。
- API 36 首次最终批次为 6 通过、1 跳过、1 失败：保存搜索后，旧测试等待首屏出现“我的频道”；新版将内容片架放在前面，频道尚未进入 LazyColumn 的可见范围。改为实际滚动到频道再验证，保留查询、标签和页数条件断言，单项复测通过。
- 部分 instrumentation 截图存在静态图层缺失或 Activity 过渡帧，对应语义节点仍可访问；不以这些图片判断控件被删除。完整首页取自持续推进 Compose 时钟的人工夹具，排序截图和真实点击路径交叉核对。早期崩溃遗留的空 PNG 未作为证据。

本轮没有完成真机、TalkBack、实站网络、所有错误态或全部播放／阅读流程验收；结果只覆盖列出的模拟器专项。模拟器最终恢复正常字体与默认分辨率。
