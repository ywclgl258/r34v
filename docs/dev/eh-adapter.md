# E-Hentai / ExHentai 原生接入

2026-11-03 接入 `ehentai`（`https://e-hentai.org`）和 `exhentai`（`https://exhentai.org`）。浏览/阅读使用 Kotlin、OkHttp、Jsoup 和原生 Android View。2026-11-04 增加独立官方登录 WebView、强制 EX 登录门禁和原生漫画瀑布流，详见 [当前网络与登录说明](system-network-auth-masonry.md)。两个站点共用 `EhAdapter` 的协议实现，分别注册身份、会话、数据和缓存。

## 参考与来源

用户指定的参考是 [Ehviewer_CN_SXJ](https://github.com/xiaojieonly/Ehviewer_CN_SXJ)，本次查阅分支 `BiLi_PC_Gamer`、提交 `d129f202b219d992ad4069dbdc70bbbd3eed5c5b`。核对了 `EhUrl`、列表/详情/图片页解析器和 Cookie 管理所反映的端点、分类掩码与字段含义。参考仓库 LICENSE 为 GPLv3；本次未复制、移植或打包其应用源码。R34V 的解析器根据实际 HTML 独立编写，测试页面和图像是原创中性素材，项目许可证保持原状。

真实原站响应仅存于 Git 忽略的 `.spike/eh/`。APK 不包含调研页面、测试素材、账号 Cookie 或参考客户端代码。

## 站点能力

- 最新、热门、十个分类；画廊/标签/上传者搜索。保留原站查询语法，上传者使用 `uploader:"名称"`。
- 列表使用紧凑模式 `inline_set=dm_l`，跟随原站 `#unext` 游标，而非自行推算页码；分类 `f_cats` 是排除位掩码。
- 详情读取标题、备用标题、页数、语言、评分、标签、上传者和预览链接。`/g/<gid>/<token>/` 与 `/s/<key>/<gid>-<page>` 均校验 HTTPS 和所属站点。
- 页数与一页预览的数量分开处理，跳页只请求目标所在的 `?p=` 预览分组，不扫描全本。
- `GalleryActivity` 原生阅读：上一页/下一页、适配大小时左右滑动、页码跳转、进度条、双击及双指缩放、放大后拖动。成功显示后保存阅读进度，加载失败不会提前推进记录。
- 画廊收藏、阅读历史、标签/上传者收藏及搜索跳转；视频继续走原播放器。
- 只获取用户打开页的 `img#img` 显示图，支持原站 `nl` 重载图源。配额/限流/移除/权限错误给出具体提示，不自动读取原图或压缩包。

## 会话导入

ExHentai 在抽屉标注“需登录及账号权限”。未登录时，首页、搜索、发现和片库均显示明确的登录门禁；点击“官方网页登录”进入官方论坛，登录后核验本站权限，再保存会话。网页登录只用于认证，浏览/阅读不使用 WebView。网页登录失败或系统 WebView 不可用时可使用系统浏览器及 Cookie 导入。

备用方式是在抽屉选择目标站点，再进入设置 → 导入站点会话。复制自己已登录浏览器对应域名的 Cookie，填写 `ipb_member_id=…; ipb_pass_hash=…`；ExHentai 可同时填写 `igneous=…`。支持大小写 `Cookie:` / `cookie:` 前缀。输入框隐藏内容，不保存表单状态，不交给系统自动填充，关闭后清空。

先用候选会话请求当前站点并验证可识别的列表，成功才替换本地会话，失败保留旧会话。原站仍决定账号权限，登录不能赋予原本没有的权限。应用不自建论坛密码表单，不保存账号密码；官方表单直接由官方网页处理。EX 明确拒绝/会话失效时要求重新登录，不回退展示已缓存的私有详情；保有有效本地会话时的网络离线重看仍可使用。

会话使用 AndroidKeyStore 的 AES-GCM 加密后保存至 `${siteId}:encrypted_cookies`，无明文存储回退；加密失败则导入失败。退出只清当前站点会话。EH/EX 不共享 Cookie，H@H、ehgt 等图片域不发送账号 Cookie。共享图片域的请求通过显式 `SiteContext` 标签固定所属站点与 Referer，避免切站时串用请求头。密钥不可用时须重新导入；应用禁用系统备份。

## 缓存与数据

阅读历史为 `${siteId}:reading_history_v1`，收藏类别为 `gallery`。操作使用条目所属站点，不依赖用户后来切换到的活动站点。

已读图片保存到私有目录 `files/gallery-cache/<siteId>/`，按图片页地址散列。详情、已读页址和图片页元数据同时保存，以便重启后离线跳到已打开的预览分组外页面。每站图片缓存上限 256 MiB，按最近使用逐出；单页响应上限 24 MiB，解码按约 600 万像素降采样。片库的“图页缓存”显示数量/大小并可单站清理。

缓存仅涵盖已打开且未被逐出的图页。未读页需要联网，当前没有整本下载、归档下载、原图下载或后台全本预取。退出账号保留个人历史和已读缓存；可分别在片库清除。
