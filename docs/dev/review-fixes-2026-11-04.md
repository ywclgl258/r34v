# 新功能审查修复

用户已明确要求「全修复」。本轮完成此前 4 项 P1、8 项 P2 的修复，并补齐修复中发现的同一路径问题。未提交、推送或发布，正式版本仍为 2.2.2 / 36；调试包名为 `com.r34v.r34v.debug`，名称为「R34V 开发版」。

## 范围与写入门槛

- 主工程流程：`code-quality-workflow`；A0 路由回执：快照 `2026-08-18`、路由 `code-quality-workflow`、已读取 `ST-A0`，没有设计目录候选。
- 决策：存储按索引持久化、切换生命周期、跨目录读删分阶段修复；订阅与写真按行为局部修复。没有重写、升级依赖或删除旧兼容路径。
- 行为约束：保留已有下载和旧数据；复制失败不提交下载位置；每个进程只绑定一个写入位置；导入来源仅允许私有/公共两个受控根目录。
- 持久格式变化仅新增 `sourceRoot`，旧标签兼容读取；旧 SQLite 缓存索引在数据库仍在时转换为缓存目录中的 `.exi`。
- 允许范围：对应 Kotlin 源码、回归测试、中性 HTML 样本及开发文档。禁止范围：版本、依赖、签名配置、私钥、发布产物和远端操作。
- 预算：各行为分阶段实施；全工作区（含用户原有未提交功能）上限 70 文件 / 6500 行变化。最终范围检查包含 staged、unstaged 和 untracked，没有通过缩小视图规避预算。
- 回退：保留用户原有改动；迁移保留私有原文件；出错停在当前阶段，不切换位置。没有用 Git reset 或覆盖用户代码。
